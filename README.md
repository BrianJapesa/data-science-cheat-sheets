# 📊 `Data Science Cheat Sheets`

A practical collection of beginner-friendly cheat sheets covering Python, SQL, statistics, data analysis, and machine learning. Designed for quick reference, revision, and hands-on learning.

## 📚 Contents

| Topic | What You'll Learn |
|---|---|
| 🐍 Python | Variables, functions, loops, and data structures |
| 🗄️ SQL | SELECT, JOIN, GROUP BY, subqueries, and window functions |
| 📈 Statistics | Probability, hypothesis testing, correlation, and regression |
| 🧹 Data Analysis | Pandas, NumPy, data cleaning, and exploratory data analysis |
| 📊 Visualization | Matplotlib, Seaborn, and effective data storytelling |
| 🤖 Machine Learning | Preprocessing, feature engineering, model training, and evaluation |
| 📉 Model Evaluation | Accuracy, precision, recall, F1-score, and RMSE |

## 🎯 Goals

- Make important data science concepts easier to revise.
- Provide concise explanations and practical code examples.
- Build a useful reference for students and aspiring data scientists.
- Encourage collaboration through issues and pull requests.

## 🚀 Getting Started

1. Browse the topic sections.
2. Copy the examples into your own Python or SQL environment.
3. Experiment with the code and adapt it to your datasets.
4. Suggest corrections or new topics through GitHub Issues.
